# Graph archive

Accumulated, verified knowledge per work area. The point: a fresh session reads
**one** file here and can act, instead of re-deriving everything from the repo,
the PDF and the transcript.

Rules for whoever writes here:

- Only facts that were **verified in this environment** (command run, output
  seen). No guesses. If something is assumed, mark it `ASSUMED`.
- Record the *decision and the reason*, not just the outcome — the reason is
  what stops the next session from undoing it.
- Record **dead ends** too ("tried X, it failed because Y"). That is the most
  expensive knowledge to re-acquire.
- Keep the "Open" section honest and current. It is the first thing read.
- Prune what is no longer true. A stale archive is worse than none.
