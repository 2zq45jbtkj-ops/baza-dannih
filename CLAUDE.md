# baza-dannih — контекст для Claude Code

## Проект

Приватная база данных учеников вокального педагога Николая (методы EVT/CVT/Dr. Vox Therapy). Один файл `index.html` (~5000 строк), ванильный JS без сборки, роутинг через `render()`/`state.activeTab`. Отдельный проект от Telegram Mini App — см. `../Telegram Mini App - your_vocal/.../CLAUDE.md` для бота.

- **Prod URL:** `baza-dannih.vercel.app`
- **GitHub:** `git@github.com:2zq45jbtkj-ops/baza-dannih.git` (main)
- **Vercel project:** `prj_Jpv5XO4ATEW2xA6EJ4g8LUpysixZ`, team `team_bu9F0zOqL8isyjDABasvhj70`
- **Деплой:** push в main → Vercel автоматически собирает. Node 24.x (`package.json engines`).
- **Локальный дев-сервер:** `.claude/server.js` — раздаёт `index.html` с диска, проксирует `/api/*` на живой `baza-dannih.vercel.app` (т.е. локально всегда бьёт по продакшен-базе — осторожно с тестовыми действиями типа удаления).

## Доступ к сайту

Весь сайт закрыт паролем (`#site-lock` оверлей, `api/site-login.js`, env `SITE_PASSWORD`), 30-дневная сессия в localStorage (`bd_auth_ts`). Оверлей **не** показывается на `localhost`/дев-прокси и в Claude Code превью — только на проде (`baza-dannih.vercel.app`).

## Структура данных

Postgres (Neon, подключено через Vercel Storage). Схема создаётся идемпотентно в `api/_db.js` → `ensureSchema()` (паттерн: `CREATE TABLE IF NOT EXISTS` + `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` в конце функции при каждом новом поле — **так добавляются все новые колонки**, отдельных миграционных файлов нет).

Таблицы: `students`, `student_intake` (вся анкета/Кабинет, одна строка на ученика, JSONB для структур/качеств/модов), `lesson_log` (Дневник занятий), `field_dicts` (общие словари для компонента Справочник), `player_tracks` (дистанционный плеер).

## API (`/api/*`)

- `students.js` — CRUD учеников, статус, телеграм-токен
- `intake.js` — GET/POST анкета ученика (весь Кабинет одним объектом, названные колонки — не free-form JSONB)
- `lessons.js` — Дневник занятий
- `dicts.js` — словари для Справочника (pinned/added варианты)
- `student-public.js` — публичный профиль по telegram-токену (дёргает Telegram Mini App)
- `admin-auth.js` — два 13-символьных ключа для админ-режима в Mini App
- `site-login.js` — пароль от всего сайта
- `player-auth.js`, `player-tracks.js`, `player-upload.js` — дистанционный плеер (см. ниже)
- `health.js` — healthcheck

## Экраны

Сайдбар слева: поиск, счётчик, 🌙/☀️ переключатель темы, ⏱/🔒 кнопка маскировки имён (ручной тумблер — скрывает имена **других** учеников, пока открыта карточка текущего; состояние держится, пока не кликнешь снова), список учеников, «+ Добавить ученика». Статус-дропдаун ученика (Активный/Пробный/Пауза) в карточке содержит ещё и «Удалить ученика ⌘⌫» — то же самое доступно по горячей клавише Cmd/Ctrl+Backspace.

Карточка ученика — 4 вкладки:

| Вкладка | Что внутри |
|---|---|
| **Кабинет** | Аккордеон из секций: Общее (возраст/тип голоса/цель/жанр/диапазон), Голосовой анамнез (ЛОР, нагрузка, сон и т.д.), Артикуляционные особенности (дефекты речи — выбор буквы → карточка с методами постановки, у каждого метода кнопки ✓/✕ «сработало/не сработало»), Голосовые аттракторы (13 структур EVT, любое отклонение от нейтрали подсвечивается терракотовым + шкала критичности 1–10), Качества голоса и CVT (10 качеств EVT + 4 мода CVT, клик меняет статус есть/частично/нет + metallic-слайдер), Референс-запись на входе (рекордер, светлый блок в тёмной теме для контраста), Записи с уроков |
| **Дневник занятий** | «Новая запись» (дата, тема, диапазон, цель, шаги урока, интенсивность/оценка 1–10, новые проблемы, домашнее задание по уровням A–D, запись голоса), «Тренд по срезам» (SVG-график оценок), «Записи занятий» (история карточек с мини-плеерами — тёмные, в отличие от основного рекордера) |
| **Колесо баланса и срезы** | Темы по уровням A–D, два варианта отображения: радар-диаграмма («Колесо») или горизонтальные шкалы 0–10 («Шкалы»); сравнение со срезами по датам |
| **Репертуар** | «Сейчас работаем над» (текст) + «Хотим спеть в будущем» (список песен) |

## Компонент «Справочник»

Общий переиспользуемый list-picker (единичный и множественный выбор) — используется ~34 раза по всему Кабинету. Капсулы-чипы в поповере, min-width 340px/max-width 480px (чтобы длинные варианты не обрезались), текст переносится, а не клипается. «+ Добавить свой вариант» пишет в `field_dicts`. Детали — `kbSpravochnikControl`/`kbSpravochnikSingleControl` в `index.html`.

## Дизайн-система

- Светлая тема: фон `#F2ECE7`, панели `#fff`, текст `#2E2A27`, акцент терракота `#AE5F3F`/`#8A3324`, линии `#E4E0DA`
- Тёмная тема (`body.dark`): фон `#1C1A18`, панели `#26221F`, текст `#EFE9E3`, линии `#3A342F`, муted `#9C9188` — переключается через CSS-переменные в `:root`/`body.dark`, но **точечные элементы с захардкоженными hex-цветами (не var()) регулярно всплывают как баги** — при добавлении нового UI всегда использовать `var(--bg)/--panel/--text/--line/--muted`, не хардкодить светлые hex
- Уровни A–D: терракота/синий/жёлтый/фиолетовый (`--lvlA..D`)
- Даты: нативные `<input type="date" lang="ru">` — без `lang="ru"` браузер показывает mm/dd/yyyy вместо дд.мм.гггг независимо от `<html lang="ru">`

## Повторяющиеся грабли

- Превью-скриншот в Claude Code иногда рендерит сплошной пустой кадр без видимой причины — DOM/computed-style проверка через `preview_eval` надёжнее, чем доверять одному скриншоту
- Клик, меняющий только часть state, может не затронуть DOM-узлы, которые рендерятся другой функцией (пример: `toggleMask()` менял `_maskActive`, но кнопка `#maskToggle` рендерится в `render()`, а не в `renderStudentList()` — пришлось патчить узел кнопки вручную)
- Новое поле в `intake`/`lesson_log` не сохранится, пока не добавлено (а) колонкой в `ensureSchema()` и (б) явно в SELECT/INSERT/UPDATE конкретного `api/*.js` — таблицы не JSONB-блобы с гибкой схемой
